Three stages

Each stage builds on the one before: a model's island uses its own assets, and its game runs on its own island.

1

3D assets

Blender 5.1, Python scripts only, run headless. Every model got the same reference sheet for each asset, a size and a triangle budget. No downloads, no image-to-3D or text-to-3D.
2

Map

Unity 6000.5.6f1, C# editor scripts in batch mode, Built-in Render Pipeline. A 400 x 400 m island built from one top-down map with the model's own assets. Terrain, water and roads come from code.
3

Gameplay

One player against 24 bots with the full match loop: drop, storm, loot, building and editing, harvesting and destruction, then menus and sound. Fortnite is the stated reference.

Same rules for all four

Engine
Unity 6000.5.6f1, Built-in Render Pipeline. Work only through C# editor scripts run in batch mode.
3D
Blender 5.1, Python (bpy) only, run headless. Everything built procedurally from scratch.
Forbidden
Asset Store or downloaded models, textures, terrains and prefabs. Any AI image or 3D generation.
Allowed
Official packages from the Unity registry. The models took the character animations from Mixamo.
Sound
Gemini and Muse generated effects and simple music in code, using noise and tones. Claude started with synthesized sound too, then replaced firearm shots with recordings from The Free Firearm Sound Library, while keeping the other effects synthesized. GPT also added recorded gunshots from that library, nature recordings from Park ambiences, and footsteps and impacts from Kenney Impact Sounds.
Naming
Labels on recordings say "test 1" for the 3D assets stage and "test 2" for the map stage.

Who recorded what

Played by hand
8 screen recordings of a person playing the games, pinned at the top of Stage 3.
Recorded by the models
Everything else in Stage 3. The models scripted their own showcases or let an autopilot drive normal player input. Conditions are on each card, for example damage multipliers and selected takes.
Turntables
4-second EEVEE renders in Stage 1, made with the same comparison render script for every model.

Read this before comparing

  • GPT got extra attempts. Several long manual rounds went into its weapon grip and its island, plus a polish try with Astra.
  • Gemini's first showcase videos were reworked. Its original full match was staged: a hidden director eliminated bots off camera and teleported opponents to the player. Both versions are in Stage 3.
  • Muse Wonder's bill covers its level and HUD sessions. Later development by another model is not counted, so its game and its bill do not line up one to one.
  • Claude's later help on the other games is not on any bill. The same goes for recording queues and building this library.
  • All cost and time figures are scenario estimates, not measured usage or verified spending.
