# ammo_box

- Preview: `runs/claude/test1/ammo_box/preview_ammo_box.png`
- Triangles: 2,928 (budget 5,000)
- Size: 0.53 x 0.28 x 0.25 m case, 0.32 m with the handle
- Objects: `ammo_box_base`, `ammo_box_rounds`, `ammo_box_lid` (separate, pivot on the back hinge line; rotate about X to open)
- Materials: `mat_olive`, `mat_olive_light`, `mat_olive_dark`, `mat_iron`, `mat_brass`, `mat_copper`
- Self-correction loops: 2 (the rim was a solid slab that covered the opening; then the rounds sat too low to see). The open pose was checked in a separate render; the shipped files have the lid closed.

Weakest: the chamfered corner silhouette of the reference is only hinted at by bevels, and the bullet emblem is a raised shape rather than an engraved outline.
